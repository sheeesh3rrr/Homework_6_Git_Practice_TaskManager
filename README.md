# TaskTracker

Консольное приложение для управления списком задач.

## Описание проекта

**TaskTracker** — это простой менеджер задач, работающий в терминале. Приложение позволяет создавать задачи, просматривать их, менять статус и удалять. Задачи сохраняются в текстовый файл `tasks.txt`.

Приложение поддерживает два режима интерфейса, которые переключаются через файл конфигурации `config.txt`:
- **Development** — простое текстовое меню с вводом номера пункта
- **Production** — красивое меню со стрелочной навигацией

## Структура проекта

```
TaskTracker/
├── TaskTracker.sln              # Solution-файл
├── config.txt                   # Файл конфигурации (Development / Production)
├── tasks.txt                    # Файл с сохранёнными задачами (создаётся при сохранении)
└── TaskTracker/
    ├── TaskTracker.csproj       # Файл проекта
    ├── Models/                  # Модели данных
    │   ├── TaskItem.cs          # Класс задачи
    │   ├── TaskStatus.cs        # Перечисление статусов
    │   └── TaskPriority.cs      # Перечисление приоритетов
    ├── Services/                # Сервисы (бизнес-логика)
    │   ├── TaskService.cs       # Управление списком задач
    │   ├── FileStorage.cs       # Сохранение/загрузка из файла
    │   └── ConfigReader.cs      # Чтение конфигурации
    └── UI/                      # Пользовательский интерфейс
        ├── Program.cs           # Точка входа
        ├── ConsoleUI.cs         # Логика интерфейса
        └── Menu.cs              # Стрелочное меню (Production)
```

## Описание классов

### Models (Модели данных)

**TaskStatus** — перечисление (`enum`) возможных статусов задачи:
- `New` — новая задача
- `InProgress` — задача в работе
- `Done` — задача выполнена

**TaskPriority** — перечисление приоритетов задачи:
- `Low` — низкий
- `Medium` — средний
- `High` — высокий

**TaskItem** — класс, описывающий одну задачу. Содержит поля: `Id`, `Title`, `Description`, `Status`, `Priority`. Метод `ToString()` возвращает строковое представление задачи для вывода на экран.

### Services (Сервисы)

**TaskService** — класс, который управляет коллекцией задач. Хранит задачи в `List<TaskItem>` и автоматически назначает каждой задаче уникальный `Id`. Предоставляет методы для добавления, удаления, поиска и изменения статуса задач.

**FileStorage** — класс для сохранения задач в текстовый файл и загрузки из него. Каждая задача записывается в одну строку, поля разделяются символом `|`.

**ConfigReader** — класс для чтения файла конфигурации `config.txt`. Определяет режим работы приложения (`Development` или `Production`).

### UI (Интерфейс)

**Program** — точка входа в приложение. Создаёт экземпляры сервисов, считывает конфигурацию и запускает интерфейс.

**ConsoleUI** — основной класс интерфейса. В зависимости от режима показывает простое текстовое меню или стрелочное меню. Обрабатывает действия пользователя: просмотр задач, добавление, изменение статуса, удаление.

**Menu** — статический класс, реализующий стрелочное меню для режима Production. Позволяет перемещаться по пунктам меню стрелками вверх/вниз и выбирать пункт клавишей Enter.

## Конфигурация

Файл `config.txt` находится в корне репозитория. Первая строка определяет режим:
- `Development` — упрощённый интерфейс (ввод номера пункта)
- `Production` — стрелочное меню с навигацией клавишами

## Запуск

из корня репозитория:
```bash
dotnet run --project TaskTracker
```
